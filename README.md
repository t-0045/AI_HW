### 2. על מה הדאטהסט? (Data Dictionary)

הדאטהסט עוסק בחיזוי רמות שכר של עובדים בעולם ההייטק והטכנולוגיה על בסיס מאפיינים מקצועיים ואישיים.

* **`Salary` (משתנה המטרה - $y$):**
  * שכר שנתי בדולרים ($). זהו המשתנה הרציף שאותו המודלים שלכן צריכים לחזות.
* **`YearsExperience` (שנות ניסיון - $X$):**
  * מספר שנות הניסיון המקצועי של העובד/ת (משתנה מספרי רציף).
* **`Age` (גיל - $X$):**
  * גיל העובד/ת בשנים (משתנה מספרי).
* **`Gender` (מין - $X$):**
  * מין העובד/ת (`Male` / `Female` - משתנה קטגורי בינארי).
* **`EducationLevel` (רמת השכלה - $X$):**
  * השכלה אקדמית: `Bachelor's` (תואר ראשון), `Master's` (תואר שני), `PhD` (דוקטורט) (משתנה קטגורי בעל סדר הגיוני).
* **`JobTitle` (תפקיד - $X$):**
  * תיאור התפקיד המקצועי (משתנה קטגורי שמי).

### 3. דרישות ואופן ההגשה

1. **פורמט ההגשה:**
   * ההגשה תתבצע באמצעות **קובץ מחברת יחיד בפורמט `ipynb.`** (Jupyter Notebook).
   * שם הקובץ יוגש בתבנית הבאה: `FirstName_LastName_Regression_Assignment.ipynb`.
2. **מבנה המחברת:**
   * **סדר והרצה נקייה:** הקפידו להריץ את המחברת מחדש מהתחלה ועד הסוף (`Kernel -> Restart & Run All`) לפני השמירה וההגשה, כדי לוודא שאין שגיאות קוד ושכל הפלטים והגרפים מוצגים.
   * **תיעוד והסברים (Markdown):** מתחת לכל תא קוד המפיק פלט משמעותי, הוסיפו תא טקסט קצר (2-3 שורות) המסביר מה רואים בתוצאה ומה המסקנה האנליטית שלכן.
   * **גרפים:** לכל תרשים חובה לתת כותרת (`title`), שמות צירים ברורים (`xlabel`, `ylabel`), ומקרא (`legend`) במקרה הצורך.
